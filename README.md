# 纪元 · 世界历史地图

一个可运行的世界历史交互原型。首屏显示地球与时间轴；浏览粒度根据所选年代自动变为日、月或年，当前范围未收录事件时，内容可扩展到更大的时间范围。历史疆域随年份变化，可切换现代国界作地理对照。

历史内容来自**离线数据集**：英文维基百科「历史上的今天」及与英文原文对应的译文缓存。运行时不请求上游内容接口。

## 本地开发

```bash
npm ci        # Node 22.13+
npm run dev   # 默认 http://localhost:5173
npm run build # 产物输出到 dist/
```

使用 React、TypeScript、Vinext（Vite 上的 Next.js 兼容层）、Cloudflare Workers、Globe.GL / Three.js。

> 若 `npm ci` 报 `EPERM ... ~/.npm/_cacache`，说明本机 npm 缓存里有 root 属主文件。可先执行 `sudo chown -R $(id -u):$(id -g) ~/.npm`，或临时改用 `npm ci --cache /tmp/npm-cache`。

## 交互

- 地球默认缓慢旋转；按住拖动改变观察方向和速度；松手后惯性逐渐减速。仅悬停不会暂停。
- 键盘聚焦地球后可用方向键旋转、加减键缩放、空格切换自转、Home 返回全球、Enter 打开地区选择器。
- 拖动的精度随年代自动变化，不需要额外的缩放开关：

  | 拖到的年代 | 拖动单位 | 日期显示 |
  |---|---|---|
  | 1900 年及以后 | 1 天 | `1953 年 6 月 2 日` |
  | 1000–1899 年 | 1 个月 | `1453 年 5 月` |
  | 1000 年以前 | 1 年 | `公元前 350 年` |

- 内容扩展：从当前浏览粒度开始，按「该日 → 该月 → 该年 → 该年代」查找已收录事件，并提示实际显示范围。这里的空结果只表示本数据集未收录。
- 键盘聚焦时间轴后，方向键按真实日历推进一天、一个月或一年，正确处理月长、闰年与公元前后衔接；日期输入也遵循上述浏览粒度。
- 时间轴下方的列表入口显示当前时间范围；回到今天时显示往年同月同日事件。选择地区后，列表及计数按该地区过滤；全球列表也可阅读没有坐标的事件。
- 历史模式支持 Cliopatria 覆盖的公元前 3400 年至 2024 年。点击政权可筛选事件；国家/政权名称、消息与详情随右上角中英切换。超出覆盖的年代只显示中性陆地并提示无疆域资料，可手动切换现代国界。
- 「历史上的今天」跨多个年代，使用现代地图定位；打开其中一条事件即进入发生年代的历史疆域。左上角「历史疆域」可从最近有资料的年份开始浏览。
- 地区事件先过滤，再按日、月、年、年代扩大范围；事件归属始终使用其发生年份，避免把整个十年的事件套入同一张疆域图。浏览到未收录当前政权的年份时，清除地区过滤并提示。
- 时间轴下限随数据集中最早的年份生成，目前支持公元前 4004 年至当前年份的 12 月 31 日，没有公元 0 年。使用 UTC 日期，避免本地时区与夏令时偏移。
- 语言和自转偏好保存在设备本地，所选历史日期不持久化；系统偏好减少动态效果时，默认关闭自转与脉冲圈。

## 历史数据

数据集在 `public/data/events/`，由 `scripts/build-events.mjs` 生成：

```bash
npm run data:events               # 读取英文 feed 缓存，缺失时下载，并合并译文缓存
npm run data:translate            # 联网补译和修复明显重复译文，按批保存进度
npm run data:events -- --offline  # 仅使用缓存重建，不发起网络请求
npm run data:audit-translations   # 检查中文覆盖、重复内容及年/日分片一致性
```

离线构建需要 `.cache/feeds/en/` 中完整的 366 个日历日 feed。必要 feed 缺失、损坏或为空会报错，不会以空数据替换已有产物。已收录译文保存在版本化的 `data/translations/zh-Hans.json` 中，删除本地翻译缓存后仍可重建；新增原文没有匹配译文时才回退英文。在线刷新可使用 `npm run data:events -- --refresh`，不能与 `--offline` 同时使用。

`data:translate` 默认使用 Google 翻译，也可用 `--provider libre` 选择社区 LibreTranslate；服务可用性与限流会影响运行。每批使用独立编号校验对应关系，检查中文、数字及重复文本，失败项写入 `.cache/translation-report-*.json` 并以非零状态退出，不会当成已完成；`--limit 100` 可限制本轮条数。通过校验的译文逐批原子写入 `.cache/translations.json`，中断后可继续。不要并发运行多个翻译进程。

译文以**英文正文的精确文本 hash** 为键：构建合并版本化译文和本地缓存，同类别优先采用本地缓存中的新修订，人工译文优先于机器译文。正式纳入数据的译文需同步保存到版本化目录，避免仅留在本机缓存。覆盖检查不等同于逐条语义校对；数字换算、专名、引文和不确定性表述仍需复核。

- **来源与标题**：英文维基百科 `on-this-day` feed 提供正文；中英文标题分别摘取对应正文，避免以战争、人物等主题名称代替具体事件。`s` 指向原文所在日期页，例如 `https://en.wikipedia.org/wiki/October_23#Events`，来源文字遵循 CC BY-SA 4.0。
- **中文候选审核**：同一日期或同一 Wikidata QID 都不能证明是同一事件。`npm run data:zhwiki -- --offline` 可从已有完整中文日页面缓存和已缓存的 QID 对应关系生成候选索引，保留完整日期、来源和全部候选；它是可选的审核资料，不会自动替换事件正文。去掉 `--offline` 会联网解析未缓存的 QID。
- **译文呈现**：构建时使用 OpenCC 简体化。`dzSrc` 区分 `manual`、`mt` 和空值；详情标注人工译文、机器翻译或英文原文，中文正文可展开查看对应英文。机器翻译尚未逐条人工校对，文本非空率不代表准确率。
- **当前规模**：19,933 条事件、1,466 个年份、366 个日历日；6,915 条有坐标（约 34.7%）。全部事件均有中文标题和正文，其中人工译文 50 条、机器译文 19,883 条。机器译文经过自动校验和抽样修订，未逐条人工校对；统计以 `manifest.json` 为准。
- **分片**：`year/<YYYY>.json` 用于时间轴查询；`day/<MM-DD>.json` 用于「历史上的今天」。两套分片保存相同事件，构建清理过时分片，manifest 记录版本、时间、数量及最早/最晚年份；时间轴和日期输入共用其中的最早年份。
- **字段**：`t`/`te` 为中英文标题，`dz`/`de` 为中英文正文，`dzSrc` 为译文来源，`y/m/day` 为日期，`lat/lng` 为坐标，`c` 为现代国家代码，`p` 为关联地点，`q` 为关联 Wikidata 主题，`s` 为来源页。`id` 包含日期及完整事件原文摘要，同一主题同一天的不同事件不会共用 ID。类型见 `app/events-db.ts`。
- **排序与坐标**：没有可靠重要性数据时 `w` 为 `null`，界面按事件日期排序。坐标优先采用正文点名的地点，或战役、遗址等具有位置属性的关联页面；关联地点和现代国家归属仍需人工核验，不代表事件发生时的政权边界。

## 地理数据

### 历史疆域

`public/data/history/` 使用 [Cliopatria v0.2.0](https://github.com/Seshat-Global-History-Databank/cliopatria)，遵循 CC BY 4.0；完整署名、固定版本、源文件校验和及处理记录见该目录的 `ATTRIBUTION.md`。1,633 个名称实体都有中英文名称；中文来源分为精确身份匹配的 Wikidata 标签、项目复核及机器翻译，来源保存在 `nameZhSource`。英文原始名称保留。

```bash
npm run data:history              # 需要 uv；校验/缓存固定源包，生成时间分片及事件归属
npm run data:history -- --offline # 已缓存原始源包时，使用版本化名称离线重建
npm run data:history:names        # 联网刷新名称候选，受上游限流影响；日常构建不需要
```

具体输入和依赖见 `data/history/README.md`。静态资源已纳入项目，运行网站和普通 CI 验证无需访问 Wikidata 或翻译服务。刷新事件数据后，应同步重建历史事件归属索引。

疆域按来源的起止年份切换，不细分同年内的月日，不插值创造中间国界。客户端按时间段加载、缓存最多 8 个几何分片；现代国界、历史几何、加载失败和超出覆盖范围使用独立状态，旧请求不会覆盖新年份。历史政权使用独立标识；复合政权与具体政权保留多重归属。

事件索引以原始未简化疆域和事件自身的年份、坐标计算。目前 19,933 条事件均有索引条目，其中 5,771 条匹配疆域，1,476 条有多重归属。无坐标、覆盖外或来源未收录区域保留空归属，仍可在全球列表阅读。显示用几何经过简化，不能作为精确边界测量依据。

这是基于来源的历史重建，尚未逐条校验史实。来源存在沿用旧称和年代粗略的记录，例如部分 Mali Federation、Serbia-Montenegro、Estado Novo 记录延续至 2024 年；完整已知限制见 `ATTRIBUTION.md` 和界面来源说明。地图未着色区域表示未收录，不能推断无人居住。历史模式沿用现代海岸线，隐藏现代省州与城市标签。

### 现代地理

`public/data/countries.geojson` 来源于 Natural Earth 1:110m：

- 原始数据：https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson
- 许可：Public Domain，https://www.naturalearthdata.com/about/terms-of-use/
- 177 个现代地理要素，仅保留相关名称和区域字段，未改动几何。

`public/data/cities.json` 与 `public/data/boundaries/` 由脚本生成，来源与许可见 `public/data/ATTRIBUTION.md`。

`public/data/land.geojson` 将现代国家多边形融合成不带内部国界的陆地轮廓，供历史模式显示来源未收录区域。更新国家底图后可运行 `npm run data:land` 重建。

### 重新生成几何数据

```bash
python3 scripts/prepare-geography.py \
  --admin1 /path/to/ne_10m_admin_1_states_provinces.geojson \
  --places /path/to/ne_10m_populated_places.geojson \
  --china  /path/to/100000_full.json
```

`cities.json` 以紧凑元组保存 `[name, country, lat, lng, rank, capital]`；客户端用 `decodeCities` 还原，顺序即生成时的排序（首都优先、重要性、人口）。

### 国家分区与地区视图

- 现代模式的国界与省州划分不随所选年份变化。国家使用稳定配色，相邻边界尽量不同色；颜色不代表统计值。
- 展示时将原始数据中的台湾轮廓合并进中国的 MultiPolygon，统一配色、悬停、点击与地区选择；台湾不单独列项。原始来源文件保留不变，台湾相关事件使用 `country: "CHN"`。
- 悬停高亮并预览事件，点击任意国家后平滑转向、按面积放大；地区选择器仅在键盘聚焦时显示。
- 地区视图暂停自转。点击远离本土的岛屿会定位该片区，镜头处理跨 180° 经线的轮廓。

## 质量保障

`.github/workflows/ci.yml` 在每次推送与 PR 上执行回归测试、类型检查、ESLint 与构建。测试覆盖日期与时间轴、加载与错误处理、地区过滤，以及数据身份、来源和分片一致性。本地等价命令：

```bash
npm test && npx tsc --noEmit && npm run lint && npm run build
```

样式 token 定义在 `app/globals.css` 的 `@theme inline` 中。Tailwind 只会为这里出现的 token 生成工具类，新增 shadcn 组件时不要把颜色变量挪出该块，否则 `border-input` 之类的类会被静默丢弃。
