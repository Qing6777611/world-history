# 纪元 · 世界历史地图

一个可运行的世界历史交互原型。首屏仅显示大地球与细时间轴；持续自转、拖拽惯性、地区悬停和点击放大已接通；历史资料留待后续补充。

## 本地开发

```bash
npm install
npm run dev
```

使用 React、TypeScript、Vinext、Globe.GL / Three.js。启动地址以终端输出为准。构建：`npm run build`。

## 交互

- 地球默认缓慢旋转；按住拖动改变观察方向和速度；松手后惯性逐渐减速，保留最后的水平转向。仅悬停不会暂停。
- 单指拖动、滚轮缩放；键盘聚焦地球后可用方向键旋转、加减键缩放、空格切换自转、Home 返回全球、Enter 打开地区选择器。
- 现代国家轮廓提供位置参照；悬停显示本地演示事件，点击区域放大并展开小信息卡；地点标签仅在选中地区后显示，点击事件可阅读详情。
- 时间轴仅保留当前年份、细线滑块和少量刻度；拖动选择日期，方向键逐日调整，点击年份输入准确日期。
- 支持公元前 500 年至当前年份的 12 月 31 日，上限按 UTC 年份自动更新，没有公元 0 年。使用 UTC 日期，避免本地时区与夏令时偏移。
- 日期和自转偏好保存在设备本地；系统偏好减少动态效果时，初次访问默认关闭自转与脉冲圈。
- 对支持 WebMCP 的浏览器提供读取当前状态与跳转日期工具；不支持时不影响交互。

## 历史数据后续接入

`app/demo-data.ts` 是独立的数据入口。当前 48 条记录均为明确标注的交互演示场景，地点、主题和时间范围组合不作为历史事实。

正式接入时，替换 `demoEventsThrough` / `eventsAt` 并扩展模型：事件的开始与结束日期、日期精度、史料来源、地点、历史政权归属、争议说明。当前按年筛选演示场景；日级 UI 已就绪，不能将演示条目视作当天历史事件。地球不依赖特定历史资料服务。

`public/data/countries.geojson` 来源于 Natural Earth 1:110m：
- 原始数据：https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson
- 许可：Public Domain，https://www.naturalearthdata.com/about/terms-of-use/
- 177 个现代地理要素，仅保留相关名称和区域字段，未改动几何。
- 现代国界不代表任一历史年代的疆域；部分小型国家未包含在该比例尺数据中。


### 国家分区与地区视图

- 国家使用稳定的地图配色，相邻边界尽量不同色；颜色不代表统计值或历史政权。
- 展示时将原始数据中的台湾轮廓合并进中国的 MultiPolygon，统一配色、悬停、点击与地区选择；台湾不单独列项。原始来源文件保留不变，台湾相关事件使用 `country: "CHN"`。
- 悬停高亮并预览事件，点击任意国家后平滑转向、按面积放大；地区选择器仅在键盘聚焦时显示。
- 地区视图暂停自转，信息卡显示当地事件；切换时间继续保留地区。返回全球恢复之前的自转偏好。
- 点击远离本土的岛屿会定位该片区。镜头处理跨 180° 经线的轮廓，将相距 3° 内的同国岛屿合并适配。
- `app/country-geometry.ts` 隔离区域定位、球面缩放与地图配色。现有 1:110m 轮廓用于原型，大幅放大时边界会有简化。
