# 纪元 · 世界历史地图

一个可运行的世界历史交互原型。地球的持续自转、拖拽惯性、地区悬停、事件详情与可缩放时间轴已接通；历史资料留待后续补充。

## 本地开发

```bash
npm install
npm run dev
```

使用 React、TypeScript、Vinext、Globe.GL / Three.js。启动地址以终端输出为准。构建：`npm run build`。

## 交互

- 地球默认缓慢旋转；按住拖动改变观察方向和速度；松手后惯性逐渐减速，保留最后的水平转向。仅悬停不会暂停。
- 单指拖动、滚轮或按钮缩放；键盘聚焦地球后可用方向键和加减键。
- 现代国家轮廓提供位置参照；悬停显示本地演示事件，点击区域或事件标记固定详情。
- 时间轴支持全览、百年、十年、年、月尺度；按日选择，输入日期跳转，自动播放、调速及前后平移。
- 支持公元前 500 年至公元 2025 年，没有公元 0 年。使用 UTC 日期，避免本地时区与夏令时偏移。
- 日期、时间尺度和自转偏好保存在设备本地；系统偏好减少动态效果时，初次访问默认关闭自转与脉冲圈。
- 对支持 WebMCP 的浏览器提供读取当前状态与跳转日期工具；不支持时不影响交互。

## 历史数据后续接入

`app/demo-data.ts` 是独立的数据入口。当前 48 条记录均为明确标注的交互演示场景，地点、主题和时间范围组合不作为历史事实。

正式接入时，替换 `DEMO_EVENTS` / `eventsAt` 并扩展模型：事件的开始与结束日期、日期精度、史料来源、地点、历史政权归属、争议说明。当前按年筛选演示场景；日级 UI 已就绪，不能将演示条目视作当天历史事件。地球不依赖特定历史资料服务。

`public/data/countries.geojson` 来源于 Natural Earth 1:110m：
- 原始数据：https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson
- 许可：Public Domain，https://www.naturalearthdata.com/about/terms-of-use/
- 177 个现代地理要素，仅保留相关名称和区域字段，未改动几何。
- 现代国界不代表任一历史年代的疆域；部分小型国家未包含在该比例尺数据中。
